# 🛒 Sistema Loja

Projeto de estudo desenvolvido em **C#** com foco no aprendizado e prática de **Programação Orientada a Objetos (POO)**.

A ideia é desenvolver um sistema de loja do zero e evoluí-lo gradualmente, aplicando os conceitos aprendidos durante o desenvolvimento.

## 🎯 Objetivo

Praticar conceitos de POO através da construção de um sistema que simula operações básicas de uma loja, como:

* Cadastro de produtos
* Cadastro de clientes
* Criação de pedidos
* Adição de produtos aos pedidos
* Cálculo do total dos pedidos

## 🛠️ Tecnologias

* C#
* .NET

## 📚 Conceitos praticados

* Classes e objetos
* Propriedades
* Métodos
* Construtores
* Encapsulamento
* Composição
* Listas e coleções
* Relacionamento entre objetos

## 🚧 Status

Em desenvolvimento.

O projeto será evoluído gradualmente conforme novos conceitos de C# e POO forem estudados.
